# HawkPU

HawkPU is an efficient, low-latency hardware architecture for HAWK signature
generation and verification. This repository contains the synthesizable
implementation accompanying the HawkPU paper.

## Publication

R. Wang, Y. Zhu, W. Zhu, Y. Ouyang, B. Yang, H. Wang, M. Zhu, C. Chen,
A. Zhang, and L. Liu, "HawkPU: An Efficient and Low-Latency Hardware
Architecture for HAWK Signature Generation and Verification," *IACR
Transactions on Cryptographic Hardware and Embedded Systems*, vol. 2026,
no. 3, pp. 719–743, 2026.

- DOI: <https://doi.org/10.46586/tches.v2026.i3.719-743>
- Paper: <https://tches.iacr.org/index.php/TCHES/article/view/13123>

Citation metadata is also available in [CITATION.cff](CITATION.cff).

## Status

This repository is a research artifact intended to support study and
reproduction of the associated paper. It is provided without warranty and has
not been evaluated as a production-ready cryptographic implementation.
